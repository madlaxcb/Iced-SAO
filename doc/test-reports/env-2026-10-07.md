## 5. 遗留事项

1. **C.2 Windows 验证机未登记**（系统版本、GPU、缩放、输入法、传输方式 → `dev/win-verify.toml`）；`gallery.exe` 尚未在 Windows 上运行验证（M0.0 通路的后半段）。
2. xvfb 无 DRI3：Linux 内循环的视觉调试受限，快照测试（软件渲染 headless）不受影响（待 M0-P9 验证）。
3. 字体子集化工具（fonttools）未装，M2 前补。
4. cargo-deny / nextest 未装，当前用降级方案；如需完整门禁，趁联网窗口可补装。
5. 微软 CRT 动态链接问题（计划书 3.7.9 / ADR-006）：干净 Windows 环境可能缺 VC++ 运行库，需在验证机确认。
