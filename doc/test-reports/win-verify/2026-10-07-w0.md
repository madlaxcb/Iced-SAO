## 二、重要技术结论（已写入 ADR）

1. **共享 Cache 多画布在 wgpu 下只渲染第一个**（iced issue #3040 复现）；独立 Cache 全部正常 → 组件规范：**每个 canvas widget 独立 Cache**；tiny-skia 无此问题。→ ADR-005 素材
2. **透明窗口必须同时设全局 style 背景 = TRANSPARENT**，否则主题白底清屏 → ADR-003
3. iced 0.14 API 事实（`interpolate` 仅 bool、`window::frames()` 帧驱动、`keyboard::listen`、`Animation::go_mut/interpolate_with/delay`）→ orb-core 动画原语设计输入（P4 已按"无动画不订阅"实现）
4. `cargo-xwin` 交叉构建稳定可用；`cfg(windows)` 类型错误只有交叉检查能暴露（win-check 纳入 ci 必要）→ ADR-006
